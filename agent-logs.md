# Agent log

## 2026-11-19 · Paper search and implementation

- Codex reviewed the project instructions and screened recent papers using searches for `robust two-dimensional principal component analysis face recognition 2025`, `robust PCA occluded face recognition image reconstruction 2025`, and `robust linear discriminant analysis small sample image classification`. The shortlist included a robust sparse LDA method, a weighted two-dimensional PCA method, and RSSPCA. Codex chose RSSPCA because it combines a recent PCA formulation, a solver described in the paper, and a small face-recognition dataset the authors used. [Towards robust and sparse linear discriminant analysis for image classification](https://doi.org/10.1016/j.patcog.2024.110512) · [Double Layer Robust 2DPCA](https://doi.org/10.1109/TCE.2025.3602258) · [Robust sparse smooth principal component analysis for face reconstruction and recognition](https://doi.org/10.1371/journal.pone.0323281)
- Codex checked the published equations and Algorithm 1 against the authors’ MATLAB scripts. The Python solver follows the paper’s L1 stopping statistic and cumulative deflation. It uses a symmetric sparse form of the reweighted linear system to preserve exact zero loadings and exploit the local pixel-neighbor graph. The recognition experiment follows the paper’s per-subject split and z-score normalization. The public classification script uses a global split and mean centering. [Paper, sections 3–4](https://doi.org/10.1371/journal.pone.0323281) · [RSSPCA MATLAB research scripts](https://github.com/yuzhounh/RSSPCA)
- Codex checked the shape, label counts, and checksum of the authors’ resized `ORL.mat` and kept it in the ignored `data/` directory. The experiment uses five fixed outer seeds and a training-only validation split for penalty selection. Codex added RSPCA as a baseline to assess the contribution of smoothness with sparsity already present. [Benchmark face databases for face recognition and reconstruction](https://doi.org/10.6084/m9.figshare.27643026) · [Authors’ ORL matrix](https://github.com/yuzhounh/RSSPCA/blob/main/data/ORL.mat)
